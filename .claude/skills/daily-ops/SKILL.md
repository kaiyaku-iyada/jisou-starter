# daily-ops

## いつ使う
毎日、成果物ができたあと。人間に渡す作業があるとき。

## 書き方
1. ファイル名は ops/dayNN.md（NN は Day 番号、2桁）。見出しは「# Day NN（M/D 曜）お前がやること」
2. 冒頭に合計所要時間（分）を書く
3. 作業は時間帯ごとに分け、番号をつけ、順番どおりに並べる
4. 各作業は「どこで → 何を → 何を貼る／押す → 終わったら何を報告する」の形。貼る文面はファイル名と見出しで指す（例: posts/x/2026-10-16.md の「20:00」）
5. 人間に選ばせない。選択肢が要るときは AI が推奨を1つ決めて「変えるなら言ってくれ」と添える
6. 設定変更は画面の経路を書く（例: 設定 → 記事設定 → ○○をOFF）
7. 最後に「報告」の項を置く。何の数字を、どこで見て、どう貼るか
8. 明日以降の予告を3行以内で

## 禁止
- 「適当に」「いい感じに」「必要なら」
- 1作業に複数の判断を含めること
- 人間に文章を書かせること（返信・問い合わせの文面もAIが用意する）
