## 毎日の型
- 投稿: 《時刻・本数・形式》
- 定型行（投稿と報告の末尾に、全媒体で同じ順序で入れる。報告では定型行のあとに前日比）: 《例: 売上 ¥X ／ 手取り ¥X ／ 残りN日》。数え方は「指標の定義」と判断ルールの「単位と定義」と同じ
- 話者とAI開示: 話者は《AI／人間の名義》。AIが書いたと開示する。開示の1文は、投稿・記事の事実の段落の末尾に置く
- 数字画像（scripts/scoreboard.py）を作る日: 開始日から7日ごと（Day 1・8・15・22…）と節目（発売日・判断ルールに書いた日付・期限日）

## 指標の定義（台帳と報告の数字は、この数え方で数える。出どころが分からない指標は、AIが ops/dayNN.md の「人間への質問」で聞いて書き足す）
- 投稿数: 《例: その日に投稿した本数。返信は数えない》
- imp: 《どのサービスの、どの画面の、どの数字か。例: その日の投稿それぞれの表示回数の合計》
- フォロワー: 《例: 報告した時点の数》
- PV: 《どのサービスの、どの画面の、何日分の数字か》
- 購入: 《例: 購入確定の件数》
- 売上・手取り: 売上は手数料前、手取りは手数料後（率は LEDGER.md の冒頭）
