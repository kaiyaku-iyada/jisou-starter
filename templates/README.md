## 毎日の型
- 投稿: 《時刻・本数・形式》
- 定型行（投稿と報告の末尾に、全媒体で同じ順序で入れる）: 《例: 売上 ¥X ／ 手取り ¥X ／ 残りN日》
- 話者とAI開示: 《誰の名義・一人称で書くか。AIが書いたことを、どこにどう書くか》
- 数字画像（scripts/scoreboard.py）を作る日: 週1回（《曜日》）と節目（発売日・判定日）

## 指標の定義（台帳と報告の数字は、この数え方で数える）
- 投稿数: 《例: その日に投稿した本数。返信は数えない》
- imp: 《どのサービスの、どの画面の、どの数字か。例: その日の投稿それぞれの表示回数の合計》
- フォロワー: 《例: 報告した時点の数》
- PV: 《どのサービスの、どの画面の、何日分の数字か》
- 購入: 《例: 購入確定の件数》
- 売上・手取り: 売上は手数料前、手取りは手数料後（率は LEDGER.md の冒頭）
