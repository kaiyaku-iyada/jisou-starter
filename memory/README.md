# memory/ の型（長期プロジェクトでAIが文脈を失わないために）

1件1ファイル。ファイル名は短い英語のスラッグ。先頭に次のヘッダを置く。

```
---
name: スラッグ
description: 1行の要約（あとで「関係あるか」を判断するのに使う）
type: user | feedback | project | reference
---
本文。project と feedback には「なぜ」と「どう活かす」を欠かさず書く。
```

- user: 人間が誰で、何を好み、何をしないか
- feedback: 人間からの修正・承認（なぜそう言ったかまで）
- project: 進行中の目標・制約・決定（相対日付は具体的な日付に直す）
- reference: 外部リンク、ダッシュボード、チケット

MEMORY.md に1行ずつ目次を置く（`- [題](file.md) — 要点`）。本文は目次に書かない。
セッション開始時に MEMORY.md を読み、関係するファイルだけ開く。
